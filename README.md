# Wordle - Консольная игра "Угадай слово"

## Простой интерфейс
- Консольное приложение с понятным текстовым интерфейсом
- Минимальное обучение для новых пользователей
- Быстрый доступ ко всем функциям

## Основные возможности

### Угадайте слово за 6 попыток
- Загадывается случайное слово из 5 русских букв
- После каждой попытки показываются подсказки:
  - `+` - буква на правильном месте
  - `^` - буква есть в слове, но не на этом месте
  - `-` - буквы нет в слове

### Интеллектуальные подсказки
- Нажмите Enter для получения подсказки
- Система анализирует предыдущие попытки
- Предлагает слова, соответствующие известным ограничениям

## Умная система подсказок
- Автоматическая фильтрация словаря
- Исключение неподходящих слов
- Случайный выбор из возможных вариантов
- Отслеживание использованных подсказок

## Логирование игры
- Полная запись всех действий в файл `wordle.log`
- Фиксация введенных слов и результатов
- Отслеживание ошибок и исключений
- Статистика побед и поражений
